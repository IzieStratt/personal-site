Usage of automated tools and AI

Some of my GitHub pull requests, issues, and commits are made with automated tools or AI. I label them so the process is transparent.

Automated tools

This includes scripts and tools that check spelling, update dependencies, create issues, or optimize code. I label this work as Automated tools and attach automated-tools@izie.top as a co-author.

AI

AI, the thing that's supposedly going to take over coding, meaning LLMs such as ChatGPT and Claude. When I use AI to make a pull request, commit, or issue, I state so near the end and add ai@izie.top as a co-author.
