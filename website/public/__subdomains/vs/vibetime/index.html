how it counts "productive struggle"

  • A minute counts only when you were there — prompting, typing, reviewing, or watching the agent for a few minutes after a prompt. Long unattended agent runs earn nothing.
  • Everything is logged to a tamper-evident local chain; your computer sends its head to the server every minute, so hours can't be backdated or faked later.
  • Your code and prompts never leave your machine — only per-project minute totals do. You choose what (if anything) to attach when you submit a project.
  • Submitted hours are auditable: reviewers see a timeline, the hands-on/steering/watching split, and GitHub push evidence.

get it

# 1. sign in above to get your token, then on each computer:
vibetime login  -server https://vs.izie.top/vibetime/app -token vt_…
vibetime service install        # starts quietly at login

# 2. add the plugin for your AI tool (see the repo), then anytime:
vibetime status                 # your time, offline, no account needed
