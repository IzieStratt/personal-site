# team.integrationLogs

- status: documented
- verified: docs-only (live-tested 2026-09-20, not_allowed_token_type on both token scopes)
- tokens: Live-tested 2026-09-20 with app_id filter, both team- and enterprise-scoped xoxc: not_allowed_token_type both times -- session tokens are categorically not permitted to call this one, independent of Grid scope (same failure class as chat.scheduleMessage in auth-and-tokens.md). Untested whether a real xoxb/xoxp app token with the right OAuth scope can reach it. Also note: the documented change_type enum is added/removed/enabled/disabled/updated -- not app_installed/app_enabled, which the method's install-detection use case might suggest by analogy to other admin.* naming. See methods/admin-write-scope-2026-09.md.
- write-shaped name: no
- source: docs.slack.dev / slack-ruby/slack-api-ref mirror
- call: POST https://slack.com/api/team.integrationLogs

Gets the integration logs for the current team.

## Params

| name | required | type | description |
|---|---|---|---|
| `app_id` | no | string | Filter logs to this Slack app. Defaults to all logs. |
| `change_type` | no | enum | Filter logs with this change type. Possible values are added, removed, enabled, disabled, and updated. Defaults to all logs. |
| `service_id` | no | string | Filter logs to this service. Defaults to all logs. |
| `team_id` | no | string | encoded team id to get logs from, required if org token is used. |
| `user` | no | user | Filter logs generated by this user's actions. Defaults to all logs. |
