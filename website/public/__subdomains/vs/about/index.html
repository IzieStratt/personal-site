About vs.izie.top

vs.izie.top is where izie hosts side projects: small web apps, toys, parodies and reference material. It is a personal site run by one person, not a company. The code lives in the public personal-site repository on GitHub and is served from Cloudflare Workers.

What is here

  • ReDocumented: a reference for Slack's Web API covering the ~345 documented methods plus 1,900+ undocumented or internal ones found by mining Slack's clients, each with its source and how well it is verified. It has a read-only lookup API, an OpenAPI description and an llms.txt for agents.
  • vibetime: passive time tracking for building with AI.
  • lostfm: a small listening stats tracker.
  • DeGoogledDict: a dictionary card without AI-written text.
  • Plus games, emoji tools and a few parodies, all listed on the home page.

Caveats

Most of this was built quickly with AI coding tools, and none of it is tracked by Hackatime. Satire pages (Chesentir, ChopChop, the Cheese Club Store) are jokes and sell nothing. ReDocumented is unofficial and not affiliated with Slack; undocumented methods can change or disappear at any time.
